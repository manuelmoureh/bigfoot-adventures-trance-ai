6. **[DECISION] Forms submit nowhere in this build — they assemble and display a structured payload client-side ("dry run"), matching Phase 3's explicit requirement** ("form dry-run — log payloads, no send") and the GOAL_BRIEF.md §3 hard stop on sending anything and on live deploy/credentials. 7. **[DECISION] Agent Company Profile PDF is a print-optimized HTML route (`/agent-profile`) using `window.print()`, not a server-generated PDF file.** The site is a static export (`output: "export"`) with no server runtime available on GitHub Pages; there is no serverless function host wired up, and standing one up would be a scope/infra decision beyond this brief. Print CSS gives a clean, real PDF via the browser's own "Save as PDF," satisfying "renders and prints cleanly" (§8) without inventing a fake download link.
